# ADR-0005: Open-core model (OSS weights, paid SaaS)

**Date:** 2026-02-28  
**Status:** Accepted  

## Context
Need trust + adoption without losing monetization. Users want transparency in security tools; the business needs revenue.

## Decision
- Open-source the fine-tuned model weights (HuggingFace)
- Charge for the managed product: integrations, real-time remediation, dashboard, retraining ops

## Alternatives
- Fully closed SaaS: weaker trust, slower adoption
- Fully open-source only: hard monetization

## Consequences
- Community trust + credibility
- Clear paid value: convenience + continuous updates
