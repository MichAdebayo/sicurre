# Sicurre Documentation

This directory contains the living documentation for **Sicurre** (product) and **Roda/Rodalega** (agent persona).

## How to navigate
- `docs/architecture/` — product goals, system design, threat model, RGPD/privacy
- `docs/adr/` — Architecture Decision Records (ADRs): why we chose key options
- `docs/api/` — OpenAPI contract + examples
- `docs/ops/` — deployment, SLOs, monitoring, runbooks, incident templates

## Conventions
- Diagrams: Mermaid embedded in Markdown
- ADRs: immutable records; append new ADRs rather than rewriting history
- Security & privacy: assume least privilege, encrypt sensitive data, minimize retention
